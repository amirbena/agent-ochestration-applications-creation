# CLAUDE.md

This repository uses [AGENTS.md](AGENTS.md) as the canonical, repository-wide agent
instruction source. Read and follow `AGENTS.md` before performing any work here.

When operating as a specialized Agent (e.g. the Backend Agent), also read that Agent's
`SKILL.md` and its applicable policies, runbooks, and templates under `agents/<agent>/`.

This file is a bootstrap only. It does not define, duplicate, or override any
repository-wide rule. If anything here ever conflicts with `AGENTS.md`, `AGENTS.md` wins.
