# Backend Templates

Reusable implementation/reference starting points for the Backend Agent. Templates are
optional accelerants, not mandatory generated boilerplate — the Backend Agent may use,
adapt, or ignore them based on the task's approved architecture and repository-local
conventions.

No templates are included yet. Future examples, organized by framework, may include:

```text
templates/spring-boot/
templates/nestjs/
templates/fastapi/
```
